### 🔭 About

**ASTRA** és un assistent intel·ligent de codi obert dissenyat per facilitar l'astronomia amateur. 
El projecte combina la potència dels **Large Language Models (LLM)** amb el protocol estàndard **INDI** per permetre el control d'equips astronòmics mitjançant llenguatge natural.

Dissenyat amb una arquitectura híbrida IoT, el sistema executa el control de maquinari nativament en **Raspberry Pi**, mentre que la interfície web i la intel·ligència artificial operen en contenidors **Docker**, facilitant un desplegament robust i escalable.
