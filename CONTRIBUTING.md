# Contributing to ASTRA 🌌

First of all, thank you for your interest in ASTRA! Whether you are an amateur astronomer or a developer, your feedback and contributions are what make the open-source community amazing!

## 🛠️ How to Contribute

To ensure a smooth collaboration, please follow these simple steps:

### 1. Reporting Bugs
If you find a bug, please check the existing issues to see if it's already being tracked. If not, open a new **Issue** including:
- A clear, descriptive title.
- Steps to reproduce the problem.
- Any relevant information about your setup (OS, hardware, INDI version).

### 2. Suggesting Features
Ideas for new features or improvements (especially for the AI assistant or the 3D dashboard) are very welcome! Open an **Issue** with the `enhancement` label to discuss it.

### 3. Submitting Pull Requests (PRs)
If you want to contribute code, please follow this process:
1. **Open an Issue first:** Discuss the change you want to make before writing code. This ensures your effort aligns with the project's direction.
2. **Follow the stack:** Ensure your changes respect the current architecture (FastAPI/Pydantic for Backend, Svelte 5 for Frontend).
3. **Be descriptive:** Explain what your PR does and why it's beneficial.

## 📜 Coding Standards

- **Backend:** Python 3.11+, FastAPI, and strict Pydantic typing.
- **Frontend:** Svelte 5, TailwindCSS 4, and Lucide Svelte for icons.
- **Internationalization (i18n):** All user-facing strings must be defined in `astra_ui/messages/` via Paraglide-js.

## 💬 Communication
The best way to get in touch is by opening a GitHub Issue. I'll try to respond as soon as possible, but please keep in mind this is a passion project!

Clear skies and happy observing! 🔭
